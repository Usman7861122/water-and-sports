# Water and Sports

Astro + React islands + Tailwind CSS v4 + Framer Motion.

## Start
```bash
npm install
npm run dev
```

## Folders
- `src/pages` - routes
- `src/layouts` - page layouts
- `src/components/sections` - static Astro sections (no JS)
- `src/components/ui` - small static Astro pieces
- `src/components/islands` - React + Framer Motion (need a `client:*` directive)
- `src/lib` - helpers and animation variants
- `src/config` - site settings
- `src/styles/global.css` - Tailwind + design tokens
